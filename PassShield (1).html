      Inclusión-exclusión, término por término (4)

      Se cuentan las cadenas que evitan por completo ciertos tipos y se suman o restan según cuántos tipos se excluyen.

      La pendiente de cada recta es log2 N: agregar un tipo de carácter la inclina un poco, pero cada carácter extra sube la recta entera. Por eso la longitud pesa más que la variedad.

      Entropía según la longitud

      Tabla comparativa

      Estas son las fórmulas que usa PassShield. Todas salen de las técnicas de conteo del curso de Matemáticas Discretas.

      Regla de la suma (1)

      Mayúsculas, minúsculas, dígitos y símbolos no comparten elementos, así que el tamaño del alfabeto es la suma de sus cardinales.

      N = |M| + |m| + |D| + |S| = 26 + 26 + 10 + 32 = 94

      Principio multiplicativo (2)

      Cada una de las L posiciones admite N caracteres, con repetición y donde el orden importa: permutaciones con repetición.

      W = N · N · … · N = NL

      Varias longitudes (3)

      Si se aceptan longitudes de Lmin a Lmax, cada longitud es un caso disjunto y se aplica otra vez la regla de la suma.

      Wtotal = Σ NL, L = Lmin … Lmax

      Inclusión-exclusión (4)

      Para exigir al menos un carácter de cada tipo de K, se restan las cadenas a las que les falta algún tipo.

      ΣS⊆K (−1)|S| (N − Σi∈S|i|)L

      Entropía (5)

      Mide el tamaño del espacio en bits. Cada bit adicional duplica las combinaciones.

      E = log2 W = L · log2 N

      Tiempo de ruptura (6)

      Con R intentos por segundo. El nivel se asigna con el promedio para R = 1010.

      Tpeor = W / R Tprom = (W + 1) / 2R

      Límites del modelo

      El cálculo supone que la clave se eligió al azar. Las personas usan nombres, años y palabras, y un ataque de diccionario prueba eso primero. Por eso el resultado es una cota superior y PassShield muestra advertencias cuando detecta esos patrones.

      Los atacantes reales tampoco tienen una velocidad fija: depende del algoritmo de hash del sistema. Las tres velocidades son órdenes de magnitud de referencia.
